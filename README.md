# LoL Friend Watcher

League of Legends のフレンドリストを表示し、**登録したプレイヤー（複数可）がオンラインになったらデスクトップ通知／音／Discord 通知を飛ばす** Web アプリです。

![mode](https://img.shields.io/badge/node-%3E%3D18-green) ![deps](https://img.shields.io/badge/dependencies-0-blue)

---

## 仕組みと前提（重要）

Riot Games の公開 Web API（developer.riotgames.com）には **フレンドリストを取得するエンドポイントが存在しません**。
唯一の取得手段は、PC 上で動作している League クライアント本体が提供するローカル API（**LCU API**）です。

そのため本アプリは次の構成になっています。

```
League クライアント                 このアプリ                      ブラウザ
  (LCU API)                     ローカル Node サーバー
127.0.0.1:<随時変わるポート>  ──▶  5 秒ごとにポーリング  ──SSE──▶  http://localhost:7320
  lockfile から認証                 状態変化を検出                  通知・音・一覧表示
                                        │
                                        └──▶ Discord Webhook（任意）
```

* **League クライアントが起動している PC 上で動かす必要があります**（ブラウザ単体では不可能です）。
* サーバーは `127.0.0.1` のみで待ち受け、localhost 以外からのアクセスは拒否します。
* 認証情報はクライアントが生成する `lockfile` から読み取るだけで、どこにも送信しません。
* Riot の認証情報（ID / パスワード）は一切扱いません。

## 使い方

### 1. 起動

League クライアントを起動してログインした状態で:

```bash
npm start
```

ブラウザで <http://localhost:7320> を開きます。

### 2. 監視するプレイヤーを登録

フレンド一覧の右端にある **☆** を押すと監視リストに入ります（複数登録可）。
オフラインで一覧に出ていない相手は、右カラム下部の入力欄に `名前#タグ` を直接入力して追加できます。

### 3. 通知を許可

初回のみ、右上の「通知を許可」ボタンからブラウザのデスクトップ通知を許可してください。
「テスト通知」ボタンで動作を確認できます。

---

## デモ（League クライアントなしで試す）

Linux や、クライアントを起動していない環境でも UI を確認できます。

```bash
npm run mock
```

12 人のダミーフレンドが数秒ごとにランダムで状態を変えるので、☆ を付けて待てば実際に通知が飛びます。

---

## 通知の種類

| 種類 | 条件 | ブラウザを閉じていても届く |
|---|---|---|
| デスクトップ通知 | 通知を許可済み | ✗（タブを開いておく必要あり） |
| 画面内トースト＋通知音 | 常時 | ✗ |
| Discord Webhook | 設定画面で URL を登録 | **✓** |

ブラウザを閉じても確実に受け取りたい場合は Discord Webhook を設定してください。
Discord の「サーバー設定 → 連携サービス → ウェブフック」で URL を発行し、設定ダイアログに貼り付けます。

---

## 設定項目（右上「設定」）

| 項目 | 既定値 | 説明 |
|---|---|---|
| 更新間隔 | 5 秒 | LCU をポーリングする間隔（2〜60 秒） |
| 再通知の抑制 | 10 分 | 同じ相手がオン／オフを繰り返しても、この時間内は再通知しない |
| 離席中・取り込み中も通知 | ON | OFF にすると「オンライン（chat）」のみ通知 |
| 通知音 | ON | 画面内の通知音 |
| Discord Webhook URL | 空 | サーバー側からの通知先 |

設定と監視リストは `data/config.json` に保存されます。

---

## ポートを変える

```bash
PORT=8080 npm start
```

## lockfile が見つからない場合

通常は自動検出しますが、インストール先が特殊な場合は環境変数で指定できます。

```bash
LCU_LOCKFILE="D:\Games\Riot Games\League of Legends\lockfile" npm start
```

自動検出が失敗した場合は、起動中の `LeagueClientUx` プロセスのコマンドライン引数からの取得も自動で試みます。

## ファイル構成

```
server/
  index.js   HTTP サーバー・ポーリング・SSE・REST API
  lcu.js     LCU 接続（lockfile 検出 / Basic 認証 / 自己署名証明書）
  store.js   監視リストと設定の永続化
  notify.js  Discord Webhook 送信
  mock.js    デモ用のダミーデータ源
public/
  index.html / style.css / app.js   UI
data/
  config.json  保存された設定（.gitignore 済み）
```

---

## 注意

LCU API は Riot の非公式（ドキュメント化されていない）インターフェースです。
読み取りのみに使う分には一般的にツールとして広く使われていますが、クライアントの更新でレスポンス形式が変わる可能性があります。
