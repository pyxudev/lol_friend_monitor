# 0007. サーバーからの外部送信とクライアント入力の制限

- ステータス: 採用
- 日付: 2026-11-19

## 背景

ローカル版はユーザー自身の PC でしか動かなかったため、Webhook の宛先や送られてくる値をほぼ検証していなかった。
共有のサーバーで動かすと、任意のユーザーがサーバーにリクエストを送らせたり、大きなデータを保存させたりできてしまう。

## 決定

- **Discord Webhook**：`https://` で、ホストが `discord.com` / `discordapp.com` / `canary.discord.com` / `ptb.discord.com`、パスが `/api/webhooks/` で始まる URL だけを受け付ける（`isDiscordWebhook`）。送信時はリダイレクトを追わず、8 秒でタイムアウトさせる。サーバーを踏み台にして内部ネットワークなどへリクエストさせる攻撃（SSRF）を防ぐため。
- **エージェントからの入力**：フレンドは最大 1000 人とし、各文字列を正規化の段階で切り詰める。リクエスト本体は 2MB までにする。
- **監視リスト**：1 ユーザー 30 人まで。名前・タグ・メモの長さも制限する。
- **設定値**：数値は範囲内に収め、プラットフォームは決まった一覧の値だけを受け付ける。
- **cron**：`CRON_SECRET` が未設定、または一致しない場合は 401 にする。
- **レスポンスヘッダー**：`vercel.json` で `X-Content-Type-Options` / `Referrer-Policy` / `X-Frame-Options` を付ける。

## 結果

- Discord 以外の通知先（Slack など）を使いたい場合は、許可するホストを明示的に追加する必要がある。
