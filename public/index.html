設定

Riot クライアントだけ起動している場合や、VALORANT など他タイトルでのオンラインでは通知しません。 オフにしてもキュー中・チャンピオン選択・ゲーム中は必ず通知します。

エージェント（フレンド一覧・オンライン通知）

League クライアントを起動する PC で次のコマンドを実行してください（Node.js 18 以上が必要）。2 回目以降は --server / --token を省略できます。 

    npx が使えない場合はリポジトリを clone して実行します。
    

    

      
      
    


    
Riot API（エージェント停止中の試合検知）

    
    監視リストの Riot ID が試合を開始したら通知します（約 1 分間隔。ロビー・キュー中は検知できません）。
    

    

      Riot API キー
      

        
        
      

      Riot Developer Portal で発行したキーを入力します。保存時に Riot に問い合わせて有効か確認します。開発用キーは 24 時間で失効するので、Personal API Key の利用をおすすめします。
